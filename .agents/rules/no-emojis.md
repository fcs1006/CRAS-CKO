# Proibição Estrita de Emojis

1. **NÃO utilize emojis** em nenhuma parte do código-fonte, componentes TypeScript, formulários, botões, opções de `<select>`, mensagens de alerta ou textos informativos da interface.
2. Emojis tornam o sistema corporativo com aparência imatura e pouco profissional.
3. **Substitutos Permitidos**:
   - Utilize ícones do FontAwesome (`<i className="fa-solid fa-..."></i>`).
   - Use tipografia limpa, caixas de alerta estilizadas com Tailwind CSS (ex: `bg-amber-50 border border-amber-200 text-amber-900`) e rótulos bem formatados em maiúsculas/minúsculas.
